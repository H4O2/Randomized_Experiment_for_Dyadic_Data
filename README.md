# Randomized experiments for dyadic data

Code sources for **Causal inference with dyadic data in randomized experiments**, by Yilin Li, Lu Deng, Yong Wang, and Wang Miao.

Repository: [H4O2/Randomized_Experiment_for_Dyadic_Data](https://github.com/H4O2/Randomized_Experiment_for_Dyadic_Data).

## Files

- `codes/run_all.py`: simulation grids, numerical summaries, and figure generation.
- `codes/sim_core.py`: populations, randomization designs, estimators, and variance calculations.
- `codes/socfb-Caltech36.mtx`: public network input required for the Caltech and variance studies.
- `requirements.txt`: the four direct dependency versions used for the publication simulations.

Generated figures, saved results, intermediate files, and auxiliary audit/replot scripts are excluded. The code generates new populations, estimates, summaries, and figures when run.

## Run

The recorded publication environment used Python 3.10.9. From the repository root:

```sh
python3.10 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

On Windows, activate `.venv\Scripts\activate` instead. The requirements pin direct dependencies; transitive dependencies are not fully locked.

Run all simulation grids with the publication replication counts:

```sh
python codes/run_all.py --suite all --reps 500 --variance-reps 10000 --output runs/full
```

For a short execution check:

```sh
python codes/run_all.py --suite all --reps 5 --variance-reps 5 --output runs/smoke
```

The output directory contains `results/`, `fig/`, and a generated `manifest.json`. Results include populations, replicate estimates, per-cell summaries, seeds, parameters, and software versions. Reuse of an output path can replace its files, so choose a new path for each run. Generated outputs are ignored by Git.

## Individual studies

| Suite | Study |
| --- | --- |
| `main` | Uniform, binomial, and lognormal outcomes over size, propensity, and BA attachment grids |
| `caltech` | Bernoulli/complete randomization on Caltech, plus the variance studies |
| `variance` | Caltech degree perturbations and propensity sweeps only |
| `sensitivity` | Higher-order peer-effect sensitivity |
| `subsampling` | Poisson subsampling and selected-pair matching |
| `cluster` | Complete/cluster randomization on the hub-and-clique network |

Use `--suite main --distributions uniform` for the uniform study alone. Main, Caltech, sensitivity, subsampling, and cluster studies use 500 assignments per setting; variance uses 10,000.  Some comparisons share populations and random numbers by design.

All numerical simulation figures are generated by the code. The supplied schematic `blob.pdf` and the additional independent 20,000-draw verification are available in the separate full journal archive.
